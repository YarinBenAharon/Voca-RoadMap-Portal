Under evaluation

Requested capabilities we are actively assessing. These are not scheduled to a release train, and some depend on platform capabilities outside our control.

Agent overview on the home page
A live team availability summary on the landing page of the agent apps.
Agent-to-agent transfer view
Visibility of which colleague a call was transferred to, and its outcome.
Extended fields on contact import
Import additional contact attributes beyond the current field set.
Caller name on the incoming call popup
Under assessment. Depends on directory lookup behaviour in the underlying platform.
Teams presence without additional authentication
Under assessment. Depends on platform authentication capabilities outside Voca.
Report scheduler Unique call id DTMF report
There is automation and reports behind it on their end with report scheduler and they need UID to be added on the dtmf reporting.
